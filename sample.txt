However, the increasing adoption of cloud technologies has also increased cyber threats such as ransomware, insider attacks, credential theft, unauthorized access, and session hijacking [1]. Traditional perimeter-based security models assume that users and devices inside the network can be trusted after authentication, but this approach is no longer effective against modern attacks that exploit compromised credentials and trusted sessions [2].
The growth of remote work environments, mobile devices, and hybrid cloud systems has further weakened traditional security boundaries. Attackers can bypass conventional security controls through phishing attacks, privilege escalation, and credential compromise. To overcome these challenges, Zero-Trust Architecture (ZTA) was introduced as a modern cybersecurity framework based on the principle of “Never Trust, Always Verify” [3]. Unlike traditional trust-based systems, Zero Trust continuously validates users, devices, and requests before granting access to resources.
The National Institute of Standards and Technology (NIST) defined the core Zero-Trust components in SP 800-207, including the Policy Enforcement Point (PEP), Policy Engine (PE), and Policy Administration Point (PAP) [3]. These components enable continuous verification and policy-driven access control. Recent studies have shown that Zero-Trust-based systems reduce the attack surface by eliminating implicit trust and enforcing adaptive security mechanisms [4].
Access control is a major component of Zero-Trust systems. Role-Based Access Control (RBAC) manages permissions based on organizational roles, while Attribute-Based Access Control (ABAC) provides fine-grained authorization using contextual attributes such as department, device trust, location, and time restrictions [5,6]. The integration of RBAC and ABAC improves flexibility and strengthens authorization decisions in enterprise cloud environments.
To ensure data confidentiality and integrity, modern cloud systems increasingly use AES-256-GCM streaming encryption because it supports secure and efficient large-file processing [7]. RSA-based key wrapping mechanisms are also used to protect encryption keys securely. Additionally, adaptive security techniques such as Multi-Factor Authentication (MFA) and Risk-Based Authentication (RBA) aid in detecting suspicious activities through behavioural and contextual analysis [8]. Tamper-evident audit logging using SHA-512 hashing and HMAC verification further improves forensic accountability and detects unauthorized modification of system logs.
This paper presents a Zero-Trust-based enterprise cloud storage framework that integrates continuous verification, RBAC, ABAC, contextual policy evaluation, AES-256-GCM streaming encryption, RSA-based key management, Risk-Based Authentication, and HMAC-linked forensic audit logging into a unified security architecture for modern cloud environments.
2. Literature Review
The rapid growth of cloud computing has introduced major security challenges related to unauthorized access, insider threats, credential compromise, and data breaches in enterprise environments. Traditional perimeter-based security approaches are no longer sufficient because attackers can exploit trusted sessions and move laterally within organizational networks after initial authentication [9]. To address these issues, Zero-Trust Architecture (ZTA) has emerged as a modern security framework based on continuous verification and strict access control policies [1,3].
Recent studies have shown that Zero Trust improves enterprise security by eliminating implicit trust relationships and enforcing continuous validation of users, devices, and contextual information [4]. Researchers have highlighted that adaptive security mechanisms such as micro-segmentation, contextual policy evaluation, and dynamic authentication significantly reduce the attack surface in cloud infrastructures [10]. Modern enterprise environments increasingly rely on hybrid access control models that combine Role-Based Access Control (RBAC) and Attribute-Based Access Control (ABAC) to provide fine-grained authorization decisions based on organizational roles, device trust, location, and time-based policies [5,6].
Cryptographic protection has also become an important research area in cloud security systems. AES-256-GCM streaming encryption is widely adopted because it provides confidentiality, integrity verification, and efficient large-file processing with minimal memory overhead [7]. Recent frameworks additionally use RSA-based key wrapping mechanisms to securely protect symmetric encryption keys during storage and transmission [11].
Researchers have further emphasized the importance of adaptive authentication and forensic monitoring in Zero-Trust systems. Risk-Based Authentication (RBA) techniques dynamically evaluate behavioral anomalies such as suspicious login activity, unknown devices, and geographic inconsistencies before granting access permissions [8]. Tamper-evident audit logging using SHA-512 hashing and HMAC chaining has also been proposed to improve forensic accountability and detect unauthorized modification of historical records [12].
Although existing studies provide strong theoretical foundations for Zero Trust, many solutions focus only on isolated security mechanisms. Limited research has integrated continuous verification, RBAC, ABAC, contextual policy evaluation, streaming encryption, adaptive authentication, and forensic logging into a unified enterprise cloud storage framework. The proposed Secure Cloud system addresses this gap through a comprehensive Zero-Trust-based architecture designed for secure enterprise data protection.
